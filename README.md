# Think Before AI

대학생의 최초 판단, 힌트와 모범 답변 검토, 독립 수행을 기록하고 교수자가 학습 역량을 평가하는 정적 웹앱입니다.

## 실행 및 배포

- 학생용은 프로젝트 루트의 `index.html`에서 제공합니다. 병합 후 공개 주소는 [학생용](https://scienceduk-byte.github.io/think-before-ai/)입니다.
- 교수자용은 `teacher/index.html`에서 제공합니다. 병합 후 공개 주소는 [교수자용](https://scienceduk-byte.github.io/think-before-ai/teacher/)입니다.
- 로컬에서는 두 파일을 각각 열거나 프로젝트를 정적 HTTP 서버로 실행해 두 경로에 접속합니다. 기존 저장 자료를 이어서 사용하려면 동일한 사이트 주소와 브라우저를 사용하세요.
- GitHub Pages의 배포 브랜치는 기존대로 `main`, 폴더는 `/ (root)`입니다. 검토 PR을 병합하면 기존 Pages 워크플로가 실행됩니다. 두 문서는 루트의 CSS와 JavaScript를 상대 경로로 공유합니다. 서버 코드, 데이터베이스, 로그인, AI API는 필요하지 않습니다.

두 화면은 메뉴와 주소로 구분합니다. 교수자용 URL을 아는 사용자는 로그인 없이 접속할 수 있습니다. URL 분리는 접근 권한을 제어하지 않습니다. 시연에서는 가상 학번과 가상 학생 기록을 사용하세요.

## 학생 사용 안내

1. **학생용 주소**에서 예시를 선택하거나 교수자가 전달한 문제 JSON을 불러오고 학번을 입력합니다.
2. **AI 활용 전**에는 과제 이해, 최초 판단, 근거, 해결 전략, AI 활용 계획을 제출합니다. 제출 원문은 잠기며 추가 의견은 뒤 단계에 따로 적을 수 있습니다.
3. **AI 활용 중**에는 교수자가 사전 작성한 힌트를 순서대로 봅니다. 외부 AI를 실제 사용했다면 질문·응답과 수용 여부를 직접 기록합니다. 미사용을 선택하면 AI 응답 입력란이 숨겨집니다. 두 경우 모두 근거 검증과 판단 수정 또는 유지 이유를 작성하고, 제출 후 사전 작성 모범 답변과 비교합니다.
4. **AI 활용 후**에는 최종 과제 또는 요약, 새로운 문제에 대한 독립 답안, 적용한 개념, 자기성찰을 작성합니다. 이 화면에서 앞선 힌트와 모범 답변은 표시되지 않습니다.
5. 학생 파일을 내려받아 지정된 경로로 제출합니다. 진행 중인 입력과 제출 기록은 같은 브라우저에 저장됩니다.

### 기본 예시 문제

1. 일회용컵 보증금제의 효과
2. 기후변화와 과학적 증거
3. 협력학습과 학업 성취
4. 스마트폰 사용과 학습 집중력

네 문제는 가상 사례이며 각각 힌트 2개, 사고 수정 질문, 모범 답변 비교 질문, 독립 수행 문항과 채점 기준을 포함합니다. 교수자용 문제 목록에서 예시를 복제하거나 직접 수정할 수 있습니다. 학생용 기본 예시는 배포본에 포함된 버전이며, 교수자가 편집한 문제는 문제 JSON을 학생에게 전달해 사용합니다. 기존 컵 과제는 새 제목으로 v2를 제공하며, 기존 문제 스냅샷과 교수자가 따로 수정한 로컬 문제는 유지합니다. 삭제한 예시는 교수자 목록에서 자동으로 다시 추가하지 않습니다.

## 교수자 사용 안내

1. **교수자용 주소 → 문제 관리**에서 기존 문제를 선택하거나 새 문제를 등록합니다. 복제를 선택하면 새 ID로 수정해 저장할 수 있습니다.
2. 과제 내용, 학습목표, 사전 사고 안내, 힌트(1~10개), 모범 답변, 독립 수행 문항 및 채점 기준을 작성합니다. 학번 패턴과 최대 길이는 문제별로 설정합니다. 학번은 문자열이며 기본값은 숫자 8자리입니다. 예시는 `[0-9]{8}`, `[A-Z][0-9]{7}`, `[0-9]{6,10}`입니다.
3. 문제별로 학습목표와 독립 수행 문항은 필수입니다. 최초 사고 질문과 AI 활용·검증 안내, 단계별 힌트, 모범 답변과 독립 수행 채점 기준을 입력할 수 있습니다. AI 활용 안내를 비워 두면 학생 화면에서 기본 안내를 표시합니다.
4. 저장한 문제를 미리 보고 **문제 JSON 다운로드**로 학생에게 전달합니다. 교수자도 **문제 JSON 불러오기**에서 기존 파일을 가져올 수 있습니다. 저장된 것과 동일한 파일은 기존 문제를 열고, 이미 기록한 버전보다 오래되었거나 내용이 다른 같은 버전은 가져오기를 거부합니다. 같은 문제를 수정해 저장하면 버전이 증가합니다. 삭제는 현재 브라우저의 문제 목록에 적용됩니다. 학생 파일에 담긴 문제와 평가 기준은 유지됩니다.
5. **교수자용 → 학생 기록 평가**에서 학생 JSON을 불러옵니다. 여러 파일을 선택하고 학번의 전체 또는 일부로 검색할 수 있습니다. 제출 당시 스냅샷 기준으로 평가하며 같은 제출 파일을 다시 불러오면 이 브라우저에 저장된 평가를 이어갈 수 있습니다.
6. 영역별 관련 기록을 검토하고 수준과 근거 메모를 작성합니다. 강점, 보완점, 추가 학습 제안과 종합 의견은 별도 입력란을 사용합니다. JSON, CSV, 인쇄를 지원합니다.

### 3영역·4수준 통합평가

| 영역 | 배점 | 수준 1 미흡 | 수준 2 보통 | 수준 3 양호 | 수준 4 우수 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 결과 평가(R) | 30 | 0–17 | 18–21 | 22–26 | 27–30 |
| 과정 평가(P) | 30 | 0–17 | 18–21 | 22–26 | 27–30 |
| 독립 수행 평가(I) | 40 | 0–23 | 24–29 | 30–35 | 36–40 |

수준을 선택하면 범위의 최고점이 들어갑니다. 교수자는 범위 안에서 정수 점수를 조정할 수 있습니다. 범위를 벗어나면 평가 저장과 출력이 중단되며 마지막 유효 평가가 보존됩니다. 세 영역이 모두 유효하면 합계를 최종 총점으로 표시합니다. 이전 4영역 평가는 같은 제출을 다시 불러오면 별도 읽기 영역에서 확인할 수 있습니다. 필수 증거를 수집하지 않았던 이전 제출에서는 해당 새 영역이 미제출로 남습니다. AI 미사용 자체를 감점 사유로 삼지 않습니다.

## 개인정보 및 보관

이름과 연락처를 수집하는 항목은 없습니다. 학번과 답변 및 평가는 현재 브라우저에서 처리하며 자동 전송하지 않습니다. 학번이 있는 파일은 지정된 수업 제출 경로로만 전달하고 공개 GitHub 저장소에 올리지 마세요. 연구·발표용 JSON은 학번과 제출·평가 시각을 제외하며, 자유 서술에 정확히 일치하는 학번을 가립니다. 나머지 식별 정보는 공유 전에 사람이 확인해야 합니다.

브라우저 저장은 기기 간 동기화되지 않습니다. 수업 보관 정책에 따라 필요한 파일을 승인된 위치에 보관하고 보관 기간이 끝나면 다운로드 파일을 삭제하세요. 공유 기기에서는 각각 **로컬 학습 기록 삭제**, **로컬 평가와 불러온 기록 삭제**를 사용하세요. 브라우저 정책이나 저장 용량에 따라 로컬 저장이 제한될 수 있습니다. 파일 가져오기 시 크기, 필수 필드, 자료형 및 버전을 검사합니다.

정적 앱에서는 배포용 JSON이나 개발자 도구를 직접 열면 힌트와 모범 답변을 확인할 수 있습니다. 단계 잠금은 학습 절차 지원 기능입니다. 제출 JSON은 외부에서 편집할 수 있으므로 스냅샷이나 학번의 진위를 증명하지 않습니다. 독립 수행 중 외부 AI 사용을 기술적으로 완전히 차단할 수 없습니다.

### AI 활용 전·중·후와 통합평가 검증

로컬 GitHub Pages 형식의 하위 경로에서 Chrome 데스크톱(1262 CSS px), 태블릿(802 CSS px), 좁은 화면(504 CSS px) 테스트를 통과했습니다. 학생 최초 제출 잠금, AI 사용·미사용 기록, 새로고침 후 원문·임시 입력 복원, 힌트와 모범 답변 순서, 독립 수행, 학생 JSON 및 평가 JSON·CSV를 검증했습니다. 기존 문제 JSON과 제출을 가져오고 기존 평가를 별도로 표시했으며, 결과 28점·과정 24점·독립 수행 38점이 총 **90점**으로 계산됐습니다. 과정 수준 3에서 27점 입력 시 저장과 내보내기가 차단됐습니다.
