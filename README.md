# Think Before AI

대학생의 생성형 AI 활용 과제에서 최초 사고, 힌트 이후의 재구성, 모범 답변 비교, 새로운 문제에 대한 독립 수행을 기록하는 한국어 교육용 웹앱입니다. HTML, CSS, JavaScript로 구성되어 있으며 별도 설치, 로그인, AI API, 서버 코드, 데이터베이스 없이 실행됩니다.

## 실행과 GitHub Pages 배포

- 로컬에서는 프로젝트 루트의 `index.html`을 브라우저에서 엽니다.
- GitHub Pages에서는 `index.html`, `styles.css`, `assignment.js`, `app.js`, `.nojekyll`, `README.md`를 저장소 루트에 올립니다.
- 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택하고 배포할 브랜치와 **/ (root)**를 지정합니다. Pages 화면에 표시된 주소를 사용하세요.
- 앱 파일은 상대 경로로 불러오므로 사용자 사이트 루트와 저장소 이름 아래의 프로젝트 사이트에서 같은 파일을 사용할 수 있습니다. `.nojekyll`은 Jekyll 처리를 건너뜁니다.

## 학생용

1. 임의 식별코드와 최초 생각, 판단 근거, 해결 전략을 제출하면 힌트가 열립니다.
2. 수정한 생각과 변경하거나 유지한 이유를 제출하면 모범 답변이 열립니다.
3. 자신의 답변과 모범 답변을 비교해 차이점과 한계를 적습니다.
4. 새 독립 수행 문제에 직접 답합니다. 이 단계의 화면에는 앞선 힌트와 모범 답변이 표시되지 않습니다.
5. 완료 화면에서 JSON 파일을 내려받아 교수자에게 전달합니다. 각 제출에는 원문과 제출 시각이 기록되며 앱에서 다시 편집할 수 없습니다. 작성 중이나 다운로드 전에 새로고침하거나 탭을 닫으면 현재 세션의 기록이 사라집니다.

## 교수자용

학생 JSON을 불러오면 두 문제와 4단계 제출 원문을 확인할 수 있습니다. 각 기준의 수행 기술문을 읽고 수준을 선택하세요. 입력한 평가를 JSON으로 내려받거나 인쇄용 화면에서 인쇄 또는 브라우저의 PDF 저장 기능을 사용할 수 있습니다.

| 평가 기준 | 배점 |
| --- | ---: |
| 사전 사고의 논리성 | 20 |
| 사고 수정과 재구성 | 25 |
| 비판적 검토 | 15 |
| 독립적 문제해결 | 40 |

수준 1~4에는 배점의 25%, 50%, 75%, 100%를 적용합니다. 네 기준의 환산 점수를 합산하며 총점은 100점입니다. 글자 수만으로 사고력을 평가하거나 AI 활용량만으로 감점하지 않습니다. 교수자가 학생 기록에 근거해 최종 평가합니다.

## 예시 과제 변경

`assignment.js`에서 과제 식별자와 제목(`id`, `title`), 최초 문제(`problem`), 힌트(`hint`), 모범 답변(`model`), 독립 수행 제목과 문제(`independentTitle`, `independent`)를 수정합니다. 과제 내용이 바뀌면 `id`도 변경하고 `app.js`의 루브릭 기술문이 새 과제에 맞는지 확인하세요. 기존 제출을 평가할 때는 해당 과제 버전의 앱을 사용합니다.

제출 JSON에는 스키마 버전, 과제 식별자, 학생 코드, 단계별 제출 시각과 원문이 포함됩니다. 평가 JSON에는 과제와 학생 식별 정보, 평가 시각, 기준별 선택 수준과 기술문, 환산 점수, 총점, 피드백이 포함됩니다.

## 데이터와 단계 잠금

학생 데이터와 교수자 피드백은 현재 브라우저에서 처리하며 서버로 전송하지 않습니다. 실명 대신 4~32자의 영문, 숫자, 하이픈 또는 밑줄로 된 임의 식별코드를 사용합니다. 사용자 입력은 HTML로 삽입하지 않고 텍스트로 표시합니다. 가져오기 파일의 크기(최대 1 MiB), JSON 문법, 스키마 버전, 과제 식별자, 단계 구조, 제출 시각, 필수 입력을 검사합니다.

단계 잠금은 학습 절차 유도 기능이며 보안 기능이 아닙니다. 정적 앱은 힌트와 모범 답변을 브라우저에 전달하므로 개발자 도구나 소스 파일로 내용을 볼 수 있습니다. 다운로드한 JSON도 외부에서 수정할 수 있으므로 앱의 잠금과 구조 검사는 제출의 진위를 보증하지 않습니다. 독립 수행 중 외부 AI 사용은 기술적으로 차단할 수 없습니다.

로컬 HTTP 서버의 `/think-before-ai/` 경로에서 Chrome 헤드리스 브라우저로 실행했습니다. 데스크톱(1262 CSS px)과 좁은 화면(491 CSS px)에서 아래 브라우저 검사를 통과했습니다.

| 검사 | 결과 |
| --- | --- |
| 학생 학습 흐름 | 잘못된 식별코드와 공백 입력 거부, 제출 후 단계별 힌트·모범 답변 표시, 독립 수행 화면에서 둘 다 미표시, 4단계 완료와 이전 입력란 제거 확인 |
| JSON 내보내기·불러오기 | 브라우저 다운로드용 JSON과 파일명 확인, 생성한 JSON 재가져오기, 공백·줄바꿈을 포함한 원문 보존, HTML 형태 입력의 텍스트 표시, 잘못된 문법·구조와 1 MiB 초과 파일 거부 확인 |
| 루브릭과 평가 결과 | 전체 수준 선택 전 내보내기 버튼 잠금, 수준 4·3·2·1에서 56.25점, 피드백 및 평가 JSON, 인쇄용 화면 진입과 복귀 확인 |
| 하위 경로와 반응형 UI | 하위 경로에서 HTML·CSS·JavaScript 모두 HTTP 200, 화면 너비를 넘는 가로 스크롤 없음, 방향키로 탭 전환 확인 |

실제 GitHub Pages 게시와 프린터 출력은 수행하지 않았습니다.
