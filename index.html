학습 문제 불러오기

교수자가 전달한 JSON을 선택하세요. 파일이 없으면 기본 예시 문제로 시작할 수 있습니다.

문제 파일을 직접 열면 힌트와 모범 답변을 볼 수 있습니다. 단계별 공개는 학습 절차를 돕습니다.

현재 입력과 학습 기록은 이 브라우저에 저장되며 다른 기기와 동기화되지 않습니다. 공유 기기에서는 작업 후 아래 버튼으로 기록을 지우세요.

    학생의 기록을 근거로 수준을 선택하고 피드백을 작성하세요.

    문제 관리

    문제는 현재 브라우저에 저장됩니다. 저장한 문제를 학생에게 배포하려면 JSON 파일을 전달하세요.

    배포용 파일에는 힌트와 모범 답변이 들어 있습니다. 학생은 파일을 직접 열어 내용을 볼 수 있습니다.

    문제 등록 및 편집
    학번 형식

    예를 들어 숫자 8자리는 [0-9]{8}, 영문 1자와 숫자 7자리는 [A-Z][0-9]{7}입니다.
